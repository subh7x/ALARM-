# Alarm Clock PWA

GitHub Pages-ready Progressive Web App.

Files:
- index.html
- style.css
- script.js
- manifest.json
- sw.js
- icons/icon-192.png
- icons/icon-512.png

Upload all files while preserving the folder structure. Open the GitHub Pages URL over HTTPS, then use the browser's Install/Add to Home Screen option.

Note: browser/OS background execution can limit exact alarm behavior when the app is fully closed. For the most reliable alarms, keep notifications enabled and test on the target phone/browser.
